# 講師流程：打包、更新、課前準備

給講師和助教看的，不會發給學員（`_help/` 已經在 `.gitattributes` 裡設成 `export-ignore`）。
學員操作手冊是根目錄的 `README.md`。

---

## 1. 打包發布

`git archive` 會自動排除 `.gitattributes` 裡標成 `export-ignore` 的東西（`tests/`、`_tests/`、`_help/`、
`documents/`、`CLAUDE.md` 等），不用手動挑檔案。**打包前先 commit**，因為它只打包 commit 過的內容。

| 用途 | 指令 | 含 `_my/` |
|---|---|---|
| 第一次安裝包 | `git archive --format=zip -o W1_full.zip HEAD` | ✅ |
| 更新包 | `git archive --format=zip -o W1_update.zip HEAD -- . ":(exclude)_my"` | ❌ |

第一次安裝包包含 `_my/`（目前只有空資料夾佔位），學員解壓後就有 `_my/` 可以存檔。

---

## 2. 發新版時學員怎麼更新

| 這次更新有沒有**刪除或搬移**檔案？ | 發哪一包 | 學員怎麼做 |
|---|---|---|
| 有，或不確定 | 第一次安裝包 | 照 README §7 重灌 SOP |
| 沒有，只有新增或修改 | 更新包 | 直接解壓到專案資料夾，選「全部取代」 |

為什麼要這樣分：

- **直接覆蓋不會刪掉舊檔案。** 被刪除或搬走的腳本會留在學員電腦上；有 `class_name` 的腳本出現兩份時，
  Godot 會報類別名稱重複。
- **更新包不含 `_my/`**，所以直接覆蓋不會動到學員存在 `_my/` 的關卡。
- 重灌 SOP 最後是學員的 `_my/` 蓋掉出廠版，方向正確，而且不會殘留舊檔。

**有用 GitHub 的學員**（自己建 repo，不是 fork）不管發哪一包都照 README §7.2：保留 `.git/` 和 `_my/`，
其他全刪再解壓。不能照 §7.1 刪整個資料夾，否則 `.git/` 會一起消失，跟 repo 斷線。

確認有沒有刪除或搬移：`git diff --stat --diff-filter=DR <上次發布的 commit> HEAD`，沒有輸出就是沒有。

**房間制與軟重生那次更新（progress.md 階段 16）刪掉了 `levels/_shared/Respawn.gd`，一定要發第一次安裝包。**
學員在 `_my/` 裡已經存好的關卡還掛著舊的 `Respawn` 節點，打開時會報找不到資源、節點顯示紅色。
請學員：選取紅色的 `Respawn` 節點按 **Delete** → 從 `blocks/` 拖一個 `RespawnHandler.tscn` 進關卡 → 存檔。
同一批更新（階段 17）也搬了 `ValueSettings`、拿掉 `_my/my_controls.gd`：學員關卡裡紅色的 `ValueSettings`
要刪掉重拖 `blocks/ValueSettings.tscn`；紅色的 `MyControls` 刪掉，底下的按鍵觸發器改拖到 `KeySettings` 底下重新連線。
按鍵觸發器的 `key_source` 下拉選單也重新排過順序（U87），學員已經放好的按鍵觸發器要**重新選一次**
`key_source`，不然按鍵來源會跑掉（例如原本「自訂按鍵」會變成「滑鼠左鍵」）。
原本的 `action` 欄位也改名成 `same_key_as`，選過的值會不見，要重選。

**重灌之後，主場景要重設**：「設為主場景」寫在 `project.godot`，不在 `_my/`，重灌後會變回預設。
README §4 第 3 步、§7.1 第 6 步、§7.2 第 4 步都有提醒學員重設。有用 GitHub 的學員，主場景設定會跟著
`project.godot` commit 進他的 repo，平常換電腦不用重設，只有更新版本時要重設。

## 3. 課前檢查

- [ ] 教室電腦能執行 `Godot_v4.7.2-stable_win64.exe`（**不是 .NET 版**），不需要系統管理員權限
- [ ] **匯出範本 `.tpz` 預先下載好**，放隨身碟或雲端（官方下載約 1 GB，十幾個人同時下載教室網路會塞爆），
	  從 https://godotengine.org/download/archive/4.7.2-stable/ 的 Export templates 下載
- [ ] 第一次安裝包已經用 §1 的指令打好，放在學員拿得到的地方
- [ ] 自己用一台乾淨的電腦跑一次 README 全流程（解壓 → 匯入 → 另存玩具箱 → 匯出網頁 → 上傳）

---

## 4. 新增週次時的規則

- 新週次的起始場景放 `levels/_starts/`，讓學員自己**另存**到 `_my/`。**不要**把檔案直接放進 `_my/` 出貨，
  不然更新時會跟學員的檔案撞名。
- 出廠的 `_my/` 不放任何會被引用的檔案，維持這樣。
- 新增機制卡／Juice／零件／能力時，`.tscn` 放外層給學員拖，`.gd` 放同層的 `_scripts/`（見 `00_foundation.md` §1）。
- 每個起始場景的 Player 底下都要有 `Mechanics`、`Juice`、`Abilities` 三個空節點，另外關卡底下要有 `KeySettings`、`ValueSettings_Health`、`RespawnHandler`，
  學員才不用自己建節點、打名字。
